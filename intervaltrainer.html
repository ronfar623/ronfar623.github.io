Interval Trainer

Can you name the interval?

Press Start Round to begin.

How to play: a reference note is played, then a second note, then both notes together (style is configurable in Settings). Pick the interval from the second note back to the first (or forward, depending on direction). Use keyboard keys A, W, S, E, D, F, T, G, Y, H, U, J, K to answer, Space to replay the notes, and Enter to start or advance to the next round. Notes appear on the piano after you answer - use them to check yourself.
